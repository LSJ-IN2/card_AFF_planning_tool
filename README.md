AF 件数予測＆プランニングツール　引き継ぎ説明書
============================================================
対象：card_AFF_planning_tool-main（アップロードZIP内のソースコード）
作成目的：Streamlit未経験の担当者が運用・改修・検証できるようにする。
※この説明書はソースコードの静的確認に基づく。実データを使った実行・精度検証は未実施。

【1. アプリの概要】
実績CSVとCPNマスタExcelを使い、媒体・商品ID別の実績分析、将来のCV/コスト予測、松竹梅の単価プラン、CV最大・CPA最小の最適案、営業提出用Excelを作成するStreamlitアプリ。過去実績分析、プランニング、競合分析の3タブで構成される。TG計測とAF計測の比較機能、媒体別競合単価分析も含む。

【2. フォルダと主要ファイル】
app.py：画面、期間/媒体選択、各分析、手動設定、提出用Excel生成、画像出力。
data/loader.py：CSV/Excel読込、マスタ結合、計測実績整形、日次集計。
logic/factors.py：定常ベース、施策・曜日・需要期等の係数、単価反応、掲載状態補正。
logic/forecast.py：各係数を順番に掛けて予測CVを算出。
logic/simulation.py：松竹梅プランを生成。
logic/optimize.py：媒体×日付ごとに最適案を選択。
logic/analytics.py：月度別実績・単価帯の集計。
competitor_analysis.py：競合単価Excelの読込と可視化。
competitor_cv_analysis.py：競合単価と自社CVの比較分析。
config/constants.py：予測・補正・シミュレーションの定数。
assets/submission_template.xlsx：営業提出用Excelのテンプレート（必須同梱）。
requirements.txt：必要ライブラリの指定。
README.md：開発側の簡易仕様。
__pycache__、*.pyc：Pythonの実行キャッシュ。引き継ぎ・Git管理には通常不要。

【3. 起動方法】
(1) ZIPを展開し、app.pyがあるフォルダを作業ディレクトリにする。
(2) Python環境を用意し、pip install -r requirements.txt を実行。
(3) streamlit run app.py で起動。Streamlit Cloudで公開する場合は、同じフォルダ構成をリポジトリに保持する。
(4) assets/submission_template.xlsxを移動・削除しない。
依存ライブラリ：streamlit、pandas、openpyxl、jpholiday、matplotlib、japanize-matplotlib、plotly。バージョン範囲はrequirements.txtを参照。

【4. 入力ファイルと準備】
■ TG実績CSV
必須の列名：成果発生日時、パートナーサイト名、件数、報酬額、商品ID。
列位置の前提：A列＝成果フラグ、F列＝SID、P列＝補填、W列＝グロス。少なくともW列まで必要。列位置が変わると誤集計するため注意。
文字コード：UTF-8 BOM付き、CP932、UTF-8を順に試す。
A列成果フラグがYまたはD、かつW列グロスが0以外の行を採用。補填除外トグルON時はP列が空欄でない行を除外。CVはY・Dの有効行、コストはY行の報酬額のみを計上する。グロス単価はW列値を保持し、報酬額÷件数から逆算しない。
集計単位：日付×媒体×SID×商品ID。グロスは件数加重平均。
■ CPNマスタExcel
必須シート：「CPNマスタ」「媒体名マスタ」。任意シート：「AFコードマスタ」。
媒体名マスタはSID、媒体名が必須で、カテゴリ列がない場合は「未分類」。SID重複は後の行を採用。
CPNマスタには日付・CPN名が必要。施策日、通常期間、月度、LINE OA配信、マジ得後などの判定に使用する。列名・入力値の変更時はdata/loader.pyとlogic/factors.pyの両方を確認。
■ AF計測実績
申込/発行の実績ファイルを別々にアップロード可能。AFコードマスタに存在するコードを対象に集計する。TG実績CSVがない場合もAF実績の月度別集計・計測結果は表示できるが、従来の予測・最適化・提出用Excelは表示されない。
■ 競合単価Excel
競合分析タブで任意アップロード。競合単価推移や自社CVとの比較に使用。具体的な列仕様はcompetitor_analysis.pyのparse_competitor_workbookを確認すること。

【5. 基本操作】
(1) 「過去実績分析」側でTG実績CSV、CPNマスタExcel、必要に応じてAF申込/発行実績をアップロード。
(2) サイドバーで補填除外、商品ID、媒体カテゴリ、媒体を選択。
(3) 「過去実績分析」タブで月度別・媒体別の実績、計測差分、単価帯、定常/マジ得などを確認。
(4) 「プランニング」タブで施策①のCPN・開始日・終了日を設定。必要なら施策②を有効化。2期間は重複不可。
(5) 学習対象月度、掲載状態、その他の予測設定を確認して計算を実行。
(6) 予測ベース・係数表・掲載状態補正を確認。
(7) 松竹梅、最適プラン、手動設定を確認・調整し、提出用Excelを生成して保存。
(8) 必要に応じて競合分析タブで競合単価の推移やCV分析を実施。
※UIの表示項目は入力データの有無や設定条件に応じて変わる。

【6. 予測ロジックの要点】
・原則として、直近定常実績に存在した媒体×商品IDの組み合わせを予測対象とする。
・ベースCV・コストは予測開始日前の直近28定常日を基準に計算。
・施策係数は前年同月の同一CPN実績を基準に、直前定常期間と施策中のCV/日を比較して求める。施策種類ごとの一律固定倍率ではない。
・曜日、月初・月末4営業日、需要期、LINE OAの係数は過去実績から動的に計算する。
・マジ得後の係数は0.90（config/constants.py）。
・予測の掛け順は、ベースCV → CPN係数 → 単価反応係数 → 全体トレンド係数 → 曜日係数 → 需要期係数 → 月初月末係数 → マジ得後係数 → LINE係数。
・係数の少数サンプル補正、直近月の重み、異常値の除外、休眠媒体の判定がある。詳細はlogic/factors.pyとconfig/constants.py。
・直近30日CVがない媒体は定常予測対象から除外する設定。
・ハピタス、モッピー、LINEは、中小媒体の過去単価上限より1円高い水準を最低ラインとする補正を持つ。
・還元額そのものは今回の予測ロジックに含まない。

【7. 松竹梅と最適プラン】
基礎単価＝基礎コスト÷基礎予測CV。
梅＝基礎単価－1,000円、竹＝基礎単価、松＝基礎単価＋1,000円。
単価変更時のCV係数：松は1.15、梅は0.85、竹は1.0（1,000円単位、config/constants.py）。
候補CV＝基礎予測CV×係数、候補コスト＝候補CV×候補単価、CPA＝候補単価。
単価が0円以下の候補や基礎予測CVが0以下の行は生成しない。
「CV最大」は日付×媒体ごとにCV最大の案、「CPA最小」は同じ単位でCPA最小の案を採用する（logic/optimize.py）。最適化は単純な候補比較であり、全社予算の総額制約を解く数理最適化とは異なる。

【8. 手動設定・提出用Excel】
最適案の確認後、手動設定画面で営業用の採用件数・単価等を調整する。
提出用Excel生成はapp.pyのcreate_submission_excel、render_submission_download、およびassets/submission_template.xlsxを使用する。対象施策の月度からファイル名を構成。テンプレートのセル位置、日付枠、数式、シート名を変更する場合は、テンプレートとapp.py内の参照座標を同時に点検する。
日付枠がテンプレートの標準枠より長い場合に列・行を拡張する処理がある。期間の長短を変えたテストが必要。

【10. 注意事項】
・CSVのA/F/P/W列は位置依存。見出し名が同じでも列の挿入・削除で計算が変わる。
・YとDをCVに含める一方、コストはYのみ。集計定義を変える場合は営業側の合意が必要。
・CPNマスタ、媒体名マスタのシート名は固定。任意のAFコードマスタはなくても読めるが、AFコード照合機能に影響する。
・予測精度は実績の量、施策の前年同月実績、媒体の継続性に依存する。係数が表示されても予測の妥当性は別途検証する。
・キャッシュを使うため、マスタや実績を更新したら再アップロードして結果が変わるか確認する。
・提出用テンプレートはプログラムとは別の重要ファイル。必ずZIPに同梱。
・競合分析の入力形式は専用モジュールのパーサーに依存。競合Excelのレイアウト変更に注意。
・実績CSVやマスタは機密情報として扱い、公開GitHubリポジトリに登録しない。

【11. 引き継ぎ時の動作確認チェック】
□ Streamlitがエラーなく起動する。
□ TG実績CSVとCPNマスタExcelを読み込める。
□ 補填除外ON/OFFで該当件数が変わる。
□ 商品ID、媒体カテゴリ、媒体の絞り込みが効く。
□ TG/AFの申込・発行・差分の数値を元データと照合する。
□ 通常CPN、マジ得、LINE OA、月初月末を含む日付で係数を確認する。
□ 施策①のみ、施策①＋②の両方で予測できる。
□ 期間重複・逆転時に適切なエラーが出る。
□ 直近実績がない媒体の扱いが仕様通りである。
□ 松竹梅の単価差、CV係数、コストを手計算で照合する。
□ CV最大/CPA最小の選択結果が正しい。
□ 手動設定を変更し、提出用Excelに反映される。
□ 日数の短い/長い施策でExcelのレイアウトが崩れない。
□ 競合Excelを読み込み、グラフと自社CV比較を確認する。
□ ダウンロードしたExcelをExcel本体で開き、数値・書式・数式を確認する。

【12. 引き継ぎメモ】
このツールは複数モジュールが連動するため、app.pyだけを修正しても予測の実体は変わらないことがある。まず「入力→日次集計→係数→予測→松竹梅→最適案→手動設定→提出用Excel」の順にデータの流れを追うこと。修正前にZIPをバックアップし、同一データ・同一条件で修正前後の結果を比較すること。
